RIDE: Relocalization-Informed Depth Estimation with 3D Gaussian Splatting

Turn pose correspondences into dense metric depth.

RIDE reuses PnP–RANSAC inliers from relocalization against a metric 3D Gaussian Splatting map as sparse depth anchors. Robust global-scale estimation, bounded spatial correction, and flow-guided causal memory calibrate a frozen VDA-S prior, sustaining metric depth through short anchor gaps after scale initialization.

Core idea

One front end. Two useful outputs.

Render–match–PnP already creates geometrically verified 2D–3D correspondences for camera pose. RIDE keeps the inliers and converts their optical-axis coordinates into sparse metric depth anchors.

Input Causal RGB stream Frames through the current time
Scene map Metric 3DGS Rendered RGB and depth from a coarse pose
Relocalize Render · match · PnP-RANSAC Refined pose plus verified inliers
Reuse Query pixel–depth anchors Optical-axis depth from PnP inliers
Calibrate prior Global scale · spatial residual · temporal memory Frozen VDA-S and SEA-RAFT remain the base
Output Dense metric depth Causal output after scale initialization

The robot evaluation covers 3,012 frames along 27 routes across five real-world scenes. Every method processes the same frames. AbsRel and δ1 are scored on the intersection of each method's valid-output mask and the required registered RGB-D reference mask; TGE additionally uses shared precomputed flow and temporal-validity masks. Models use weights trained on public RGB-D sequences without robot-data training or fine-tuning. Registered RGB-D is evaluation-only, and robot PnP anchors are deployment inputs rather than held-out calibration targets.

Evidence

From verified matches to stable depth.

The interface is inspectable at the correspondence level, and the temporal behavior is evaluated across anchor outages and dynamic content.

System boundary

Training and deployment share a pixel–depth anchor interface.

Training

Controlled anchor failures

Registered depth sampled at detected feature locations provides RGB-D-derived anchors. Withholding, dropout, count caps, structured outliers, and anchor outages simulate relocalization conditions on public RGB-D videos.

Deployment

Relocalization-derived PnP inliers

The same interface receives sparse anchors from the metric 3DGS relocalization front end. The learned weights transfer without robot-data fine-tuning; RGB-D remains evaluation-only.
